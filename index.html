01. sobre mim

Quem sou eu

Sou estudante do curso técnico de Desenvolvimento de Sistemas no SENAI, em São Paulo. No curso aprendi a levar um sistema da ideia até o deploy: levantamento de requisitos, modelagem do banco, API, interface web e app mobile.

Meu principal projeto é o Protutal, nosso TCC: uma plataforma de tutoria entre alunos da rede SESI. Nele trabalhei principalmente no back-end, criando as rotas de salas, materiais, atividades, contestação de notas e desempenho, além de participar das telas do front-end.

Trabalho em equipe com Scrum e Git Flow, e uso ferramentas de IA como o Claude Code no dia a dia para acelerar o desenvolvimento sem perder o controle do código.

  • 4Sprints entregues no TCC
  • 15+Tecnologias usadas em projeto real

Projeto em destaque · TCC

Protutal

Plataforma web e mobile de tutoria entre alunos da rede SESI, com foco em Geografia. O professor transforma alunos em tutores, os tutores criam atividades e dão notas, e todos acompanham o desempenho por conteúdo e por etapa.

  • Rotas de salas, materiais, atividades, contestação de notas e desempenho
  • Upload de arquivos com Cloudinary e confirmação de e-mail com Nodemailer
  • Banco modelado do MER ao schema Prisma + PostgreSQL
  • Front web em Next.js e app mobile em React Native / Expo
  • TypeScript
  • Node.js
  • Express
  • Prisma
  • PostgreSQL
  • Next.js
  • React Native

Projeto em equipe com Cesar Castro, Luisa Santos e Ruben Rocha.
